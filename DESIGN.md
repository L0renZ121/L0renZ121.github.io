# Design system

## Direction

The portfolio is an editorial signal lab: a calm, structured alternative to the previous neon/glass dashboard. Content should feel like field notes from a curious builder, with direct paths to proof and contact.

## Three-color system

- **Primary — Signal lime:** `#c9f36b` dark theme / `#5e8f20` light theme. Use for actions, focus, active states, progress, and the strongest emphasis.
- **Base — Ink canvas:** `#111312` dark theme / `#f3f5ef` light theme. Use for the page field and the overall reading environment.
- **Secondary — Signal coral:** `#ff876f` dark theme / `#c84f3b` light theme. Use sparingly for the orbit marker, status accents, and moments that need a warmer counterpoint.

Readable text and borders use neutral tints derived from the base color. No additional semantic accent colors are introduced.

## Typography

DM Sans is the primary reading face. Space Mono is reserved for metadata, labels, shortcuts, and compact technical annotations. Display headings use tight tracking and an editorial scale.

## Composition

The page uses a wide editorial grid, asymmetric hero, compact panel surfaces, and timeline-based experience history. Sections have generous vertical rhythm, while content groups use hairline borders instead of nested card stacks.

## Interaction

The interface supports light/dark theme switching, responsive navigation, command palette navigation with `/`, project filtering and detail dialogs, resume download, contact feedback, a typing role note, scroll reveals, reduced motion, and the existing Konami-code easter egg.
