# Abhi Khatiwada Portfolio

This is a Vite + Preact single-page portfolio focused on frontend engineering, visual systems, responsive interfaces, interaction design, and accessibility.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production files are emitted to `dist/`. GitHub Pages can deploy that folder directly, or use the repository workflow in `.github/workflows/pages.yml`.
